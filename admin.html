Publish Your Changes

GitHub Pages serves static files, so this admin panel edits a working copy in your browser. To make changes live for every visitor, export the updated file and upload it to your GitHub repo.

1. Export updated content.json

Downloads a file with everything you've changed in Settings and Properties.

2. Upload it to GitHub

  1. Go to your GitHub repository in the browser.
  2. Open the data folder and click on content.json.
  3. Click the pencil (Edit) icon, delete everything, and paste the contents of the file you just downloaded — or use "Upload files" and replace it directly.
  4. Scroll down and click Commit changes.
  5. Your live site updates automatically within a minute or two.

3. (Recommended) Connect Google Sheets for real lead capture

This lets every visitor's enquiry — from any phone or computer — land in a Google Sheet you can open anytime, instead of only showing up on one browser.

  1. Create a new Google Sheet, name a tab Leads with headers: date, name, phone, interest, message.
  2. In the Sheet, open Extensions → Apps Script and paste this code:
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Leads");
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.date, data.name, data.phone, data.interest, data.message]);
  return ContentService.createTextOutput(JSON.stringify({ status: "ok" }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Click Deploy → New deployment → Web app. Set "Who has access" to Anyone, then deploy and copy the Web App URL.
  2. Paste that URL into leadsWebhookUrl in data/content.json (edit it directly on GitHub, or ask a developer to add a field for it in this panel).
  3. To read leads back into this Inquiries tab automatically, publish the Sheet as CSV (File → Share → Publish to web, choose the Leads tab, CSV format) and paste that link into leadsSheetCsvUrl in the same file.
